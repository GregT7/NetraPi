# NetraPi

Raspberry Pi dashcam that classifies stop-sign encounters (complete stop, rolling stop, run-through) on a Coral USB TPU, uploads clips to S3, and shows them on a public site.

**Site:** [netrapi.vercel.app](https://netrapi.vercel.app)

## Constraints

- Budget: **$1,000 or less**
- Vehicle: **2010 Mazda3** — reversible mounts, portable-battery power only (no 12V tap)
- Must stay **legal and safe** on public roads
